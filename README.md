# مساري



منصة اختبار توجيه جامعي لطلاب الثانوية في سوريا.



## المميزات



- اختبار تفاعلي من 18 سؤالاً

- 7 أبعاد معرفية

- 31 تخصصاً جامعياً

- 5 اتجاهات دراسية

- نتيجة: اتجاهان × تخصصان

- حفظ التقدم تلقائياً

- مشاركة النتيجة كصورة

- الوضع الداكن



## التقنيات



- Vanilla JavaScript (ES6 modules)

- HTML5 + CSS3

- LocalStorage

- Canvas API
