# مساري

منصة اختبار توجيه جامعي لطلاب الثانوية في سوريا.

## المميزات

- اختبار تفاعلي من 18 سؤالاً، تُسحب من بنك يضم 98 موقفاً
- 7 أبعاد معرفية
- 31 تخصصاً جامعياً
- 5 اتجاهات دراسية
- نتيجة: اتجاهان × تخصصان
- حفظ التقدم تلقائياً
- مشاركة النتيجة كصورة
- الوضع الداكن
- مساعد ذكي يجيب عن الاستفسارات الأكاديمية

## التقنيات

- Vanilla JavaScript (ES6 modules)، بلا مكتبات خارجية
- HTML5 + CSS3
- LocalStorage
- Canvas API

## هيكل المشروع

| الملف | الدور |
|---|---|
| `index.html` | هيكل الصفحة وشاشاتها (ترحيب، تسجيل، أسئلة، نتيجة) والنوافذ |
| `app.js` | نقطة الدخول: التخزين، محرك الاختبار، الواجهة، تصدير النتيجة، الملاحظات |
| `questions.js` | بنك الأسئلة |
| `dimensions.js` / `directions.js` / `specializations.js` | تعريف الأبعاد والاتجاهات والتخصصات |
| `scoring.js` | خوارزمية الحساب |
| `chatbot.js` / `chatbot.css` | المساعد الذكي |
| `icons.js` / `glow.js` | سجل الأيقونات، وتعديلاتها وتدرجاتها والمخطط الخطي |
| `qr.js` | مولّد QR بلا مكتبات |
| `style.css` / `glow.css` | التنسيق الأساسي وطبقة التجاوز (تُحمَّل بعده) |

## كيف تُحسب النتيجة

1. درجة كل بُعد = نسبة المرات التي اختاره الطالب حين عُرض عليه، مع قيمة أولية للتنعيم.
2. تُحوَّل الدرجات إلى متجه بترتيب ثابت (ترتيب `DIMENSION_KEYS` جزء من العقد).
3. يُحسب معامل ارتباط بيرسون بين المتجه وبصمة كل تخصص، ثم يُحوَّل إلى نسبة مع معايرة صغيرة لكل اتجاه.
4. تُجمَّع التخصصات حسب الاتجاه، ويُختار أعلى اتجاهين وأفضل تخصصين في كل منهما.
5. تُحسب الثقة من الفجوة بين الاتجاهين، وتُخفَّض إذا كانت جودة الإجابات ضعيفة (نمط ثابت، اختيارات متقاربة، أسئلة قليلة).

عند تعديل الأسئلة أو التخصصات أعد معايرة `DIRECTION_CALIBRATION` في `scoring.js` بالمحاكاة.

## التشغيل محلياً

الملفات وحدات ES، فلا تعمل من `file://`. شغّلها عبر خادم ثابت:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الإعداد

- **المساعد الذكي:** يمر الطلب عبر Cloudflare Worker (`WORKER_URL` في `chatbot.js`). مفتاح النموذج يبقى داخل الـ Worker ولا يوجد في الكود. الهيدر `X-Masari-Token` الظاهر في المتصفح ليس سراً، والحماية الفعلية (تحقق الـ Worker، حدّ للمعدل، فحص الأصل) تُضبط على الـ Worker.
- **جمع البيانات:** تُرسل بيانات التسجيل والملاحظات إلى Google Forms، وأرقام الحقول في `app.js`.
- **الإصدار:** رقم `?v=` في روابط `index.html` واستيرادات الوحدات يجب أن يكون واحداً في كل الملفات، ويُرفع عند كل نشر لإبطال كاش المتصفح.
